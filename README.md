# n8n AI Email Automation Agent 🤖

AI-powered email automation workflow
built with n8n connecting OpenAI GPT
with Gmail API.

## What It Does
- Receives natural language instructions
- AI Agent processes the request
- Automatically sends email via Gmail
- Deployed live on n8n cloud

## Workflow
Chat Trigger → AI Agent (GPT) → Gmail

## Tech Stack
n8n · OpenAI GPT · Gmail API · 
AI Agents · Workflow Automation
